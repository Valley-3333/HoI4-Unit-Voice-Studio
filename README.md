# HoI4 Unit Voice Studio

HOI4のユニット音声を、自分で録音した声に置き換えるWindows用アプリです。国・用途ごとに差し替えられます。

作者：Valley／非公式ツール

動作条件：Windows 10/11、.NET Framework 4.8以上、インストール済みのHOI4、マイク

- 本アプリケーションはChatGPT,Codexを利用して作成しています

## 導入

1. [Releases](https://github.com/Valley-3333/HoI4-Unit-Voice-Studio/releases)からインストーラをダウンロードして実行します。
2. アプリを起動します。本体とModの登録先は自動で検出します。
3. HOI4ランチャーで「Unit Voice Studio」をプレイセットに追加します。

## 使い方

1. 国・用途・音声候補を選び、元音声を聴きます。
2. 「国・用途・対象を確認しました」にチェックします。
3. 「録音開始」→「停止」で収録し、「録音を聴く」で確認します。
4. 「Modに反映」を押し、HOI4を再起動します。

その用途をすべて自分の声にする場合は、「この用途の全候補を同じ録音にする」を選んでください。

## 困ったとき

登録できない場合は「導入・登録設定」→「登録・修復」を使います。
